Sobre a biblioteca

A Biblioteca Comunitária é uma proposta desenvolvida para auxiliar na organização do acervo e facilitar o controle de usuários, empréstimos e devoluções de livros.

O sistema foi desenvolvido como parte de um projeto de Atividade Extensionista do curso de Análise e Desenvolvimento de Sistemas, utilizando Python, Flask, HTML, CSS e MySQL.

A proposta busca contribuir para o acesso à leitura e para uma organização mais simples das informações da biblioteca.
